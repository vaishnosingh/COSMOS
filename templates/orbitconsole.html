Custom Domains
Map your own domain to any Orbit application
How Custom Domains Work
1. Pick an app and set its custom domain below.
2. In your DNS provider, add a CNAME record pointing your-domain.com → this-server
3. For apex domains (e.g. example.com) use an A record pointing to this server's IP.
4. DNS propagation takes up to 48h. Once live, traffic routes directly to your container.

Supported Tech Stacks, Frameworks & Database Runtimes
Cosmos Orbit runs any workload in isolated OCI Docker containers with automated or custom Dockerfile execution
Quota: 10 Ports (4100–4999)
Frontend Frameworks
  • React, Vue 3, Svelte, Angular: Built via Node builder or Vite/Webpack, served statically through high-speed Nginx Alpine container (Port 80).
  • Next.js / Nuxt / Astro: Supported in static output mode or Node.js SSR runtime (Port 3000).
  • Static HTML5, CSS3, Tailwind: Zero-config Nginx container with Gzip compression and instant boot.
Backend Runtimes & APIs
  • Node.js 20/22: Express, Fastify, NestJS, Koa, Hono with auto-detected PORT=3000.
  • Go 1.24+: Standard Library HTTP, Fiber, Gin, Chi built with multi-stage Alpine images (<15MB, Port 8080).
  • Python 3.11+: FastAPI, Flask, Django, Uvicorn, Gunicorn with auto-entrypoint discovery (Port 8000).
  • Rust, Ruby, PHP, Java: 100% supported via custom repository Dockerfile.
Database & Storage Integration
  • Internal Cosmos ScyllaDB: Accessible to user apps on host port 9042 (Cassandra CQL driver).
  • Internal Cosmos Oort (S3): High-speed object storage on cosmos.linuxguy.space:9000 with 1-click snapshot backups.
  • External Databases: Connect to any managed PostgreSQL, MySQL, Redis, MongoDB, Supabase, Neon via DATABASE_URL env var.
  • Dedicated DB Containers: Deploy Redis/Postgres container directly into your 10-port quota.
